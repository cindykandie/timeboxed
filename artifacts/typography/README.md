# Partial historical audition

These captures predate the persistent font Settings screen. The user selected
Satoshi as the default while the comparison was still running, then requested
all four choices in Settings. The audition automation was stopped and its
temporary route, fixtures and inactive controls were removed.

Satoshi's five utility screens and specimen, plus a Clash Display specimen,
were captured. This folder does not represent a completed three-family
regression or comparison. Its build/preview logs include unsuccessful attempts
and an interrupted run. See `../font-settings/` and
`../../docs/font-settings.md` for the current implementation and validation.
